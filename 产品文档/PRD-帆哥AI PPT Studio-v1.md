# 帆哥 AI PPT Studio · 产品需求文档（PRD v1.0）

> 一句话定位：**把「AI 生成 HTML 幻灯片」和「本地可视化精修」做成一条流水线——生成即半成品，编辑即成品，全程你的文件不出本机。**
> 双引擎：Step 1 AI 生成 → Step 2 可视化编辑 → 一键导出 PPTX/PDF/PNG。中国与欧美双市场。

## 1. 产品愿景

让**不会设计的人**也能在 5 分钟内拿到一份**可继续精修、可编辑、可导出**的高质量幻灯片；让**会设计的人**把「AI 写 HTML → 最后一公里微调」这条昂贵链路，砍断成「生成 → 点改 → 导出」。

核心主张（差异化）：
- **生成的是「真 HTML 源」，不是一张锁死的图片**。源文件永远可改、可导出、可迁移。
- **编辑 100% 本地、免注册、零上传**。你的 PPT 文件不会被复制、不会被改，除非你点保存写回原文件。
- **生成免费/低价，编辑免费，AI 增强才收费**——用免费本地工具建立信任与口碑，再用云 AI 生成做变现。

## 2. 背景与问题

### 2.1 行业现状痛点
- **AI 生成强、精修弱**：Gamma / 讯飞智文 / WPS AI 等能生成，但「挪 8 像素、换一句话、改个色」回对话框 re-prompt 会丢上下文、烧 token、常改坏其他页。
- **导出锁死**：多数工具导出为图片型 PPTX 或只能在其云端编辑，无法拿到可编辑的本地源。
- **隐私焦虑**：企业/个人的 PPT 内容往往涉密，上传第三方云端有合规风险（尤其 EU GDPR）。
- **模板锁死**：封闭模板体系，设计自由受限，迁移成本高。

### 2.2 我们已具备的能力（盘点）
| 能力 | 现状 | 来源 |
|---|---|---|
| HTML 幻灯片生成 | 已有（feishu-html-slides / frontend-slides 等 skill，能把主题/文档渲染成 HTML deck） | 既有 |
| 本地可视化编辑器 | v1.0.22：open-in-place 原地编辑、拖拽移动+对齐吸附、历史快照/回滚、隔离不污染源 | 既有 |
| 可编辑 PPTX 导出 | `build_editable_pptx`（文字转可编辑文本框）✓；图片版 ✓ | 既有 |
| 本地优先/零上传 | 100% 本地，仅飞书上传为可选 | 既有 |
| 拖拽缩放（resize handle） | ✗ 缺失（仅 numeric 输入） | P0 待补 |
| 代码视图兜底 | ✗ 缺失 | P0 待补 |
| PDF/PNG/长截图导出 | ✗ 缺失 | P1 待补 |
| AI 生成闭环（Web 产品形态） | ✗ 缺失（当前是本地 skill，非 SaaS） | Step 1 待建 |

## 3. 产品形态（双引擎架构）

### 3.1 总览
```
┌──────────────────────────────────────────────────────────────┐
│                      帆哥 AI PPT Studio                        │
├──────────────────────────────┬───────────────────────────────┤
│  Step 1 · AI 生成引擎（云）    │  Step 2 · 编辑引擎（本地优先）  │
│  ─────────────────────────    │  ───────────────────────────  │
│  输入：主题/文档/URL/图片      │  打开任意 HTML（原地编辑）      │
│   ↓ LLM 结构化+撰写           │   ↓ 可视化精修（拖/缩/吸/代码） │
│  渲染成 HTML deck（可编辑源）  │   ↓ 历史快照/回滚/隔离          │
│   ↓ 「在编辑器中打开」一键流转 │   ↓ 导出 PPTX/PDF/PNG/长截图   │
└───────────────┬──────────────┴────────────────┬──────────────┘
                │   桥接层：生成产物 = 编辑器能直接吃的 HTML deck   │
                └────────────────────────────────────────────────┘
```
**关键设计**：Step 1 的产物就是 Step 2 的源格式——**同一套 HTML deck 规范**。两端共用 schema，生成即可编辑，编辑即可导出，无缝流转。

### 3.2 Step 1 · AI 生成引擎
- **输入**：自然语言主题 / 上传文档（Word/PDF/Markdown）/ 网页 URL / 参考图。
- **处理**：LLM 做大纲结构化 + 文案撰写 + 版式意图（标题页/内容页/图表页/结尾页）；调用既有 HTML 渲染能力产出**符合 deck 规范的 HTML 源**。
- **交付**：生成后在编辑器内直接打开，用户进入 Step 2。
- **形态选项**（待决策）：
  - A. **纯本地 CLI/skill**：复用现有 skill，用户自己有 API key，零服务器成本（最适合冷启动，但难收费、难规模化）。
  - B. **Web SaaS（推荐路线）**：云端生成 + 本地编辑器配套，账号体系 + 订阅收费（收费前提）。
  - C. **混合**：本地编辑器免费，云端 AI 生成按量/订阅收费（我们的推荐——见 §7）。

### 3.3 Step 2 · 编辑引擎（现有 17-帆哥PPT编辑器）
- open-in-place：打开任意位置 HTML，原地编辑写回原文件。
- 可视化精修：改字、拖拽移动、对齐吸附（已具备）；**拖拽缩放、代码视图（本期补全）**。
- 安全可追溯：自动历史快照 + 回滚 + 隔离（不污染用户项目文件夹）。
- 交付：可编辑 PPTX（文字可改）/ 高清整页图；补齐 PDF/PNG/长截图（P1）。

### 3.4 桥接层
- 生成产物 = 编辑器规范的 HTML deck（`<section class="slide">` 结构 + 系统字体栈 + 无外部字体 CDN）。
- 编辑器 `viewport-select` 已支持 16:10/16:9/9:16/4:3，生成时可指定目标比例。
- 「在编辑器中打开」= 把生成产物落到本地文件 → 调用 `/api/open` 进入原地编辑。

## 6. 与竞品差异化

| 维度 | Gamma/WPS AI/讯飞智文 | NextPPT | 我们（AI PPT Studio） |
|---|---|---|---|
| 生成→编辑无缝 | 云端一体但锁死 | 仅本地编辑 | **生成=可编辑 HTML 源，自由流转** |
| 导出可编辑 | 多为图片型 | 图片型 PPTX | **可编辑 PPTX（文字可改）** |
| 本地优先/隐私 | 弱（云端） | 强（本地） | **强（本地编辑零上传）+ 可选云端生成** |
| 设计自由度 | 模板锁死 | 通用 HTML | **HTML/CSS 真源，完全可控** |
| 收费模型 | 订阅较重 | 一次性买断 | **本地编辑免费 + AI 生成订阅**（低门槛获客） |

**最大护城河**：本地免费编辑器（真源、可编辑导出、隐私）作为流量入口与信任锚，云端 AI 生成作为变现点——竞品要么全云端锁死，要么纯本地无 AI。

## 7. 收费模型与可行性评估（重点）

### 7.1 能不能「直接打包去收费」？——诚实结论
**现在还不能直接收费。** 必须补齐 MVP 门槛（§5.1）后才有收费资格：
1. 编辑器 P0 未完成（拖拽缩放、代码视图缺失）→ 用户体验断层。
2. AI 生成引擎尚未产品化（当前是本地 skill，无账号/支付/配额）。
3. 导出缺 PDF/PNG（仅 PPTX）。
4. 无账号/支付/合规基线。

**但路径清晰、成本低**：核心引擎（生成 skill + 本地编辑器）已跑通，主要是「产品化封装 + 补齐交付格式 + 接入账号支付」。

### 7.2 收费模型（推荐：Freemium 混合）
- **免费层**：本地编辑器全功能永久免费（改字/拖拽/缩放/吸附/代码视图/历史/导出 PPTX）；AI 生成 **限免 N 次/月** 或带水印。
- **Pro 订阅**：AI 生成不限量/高配额 + 全部导出格式（PDF/PNG/长截图）+ 无水印 + 批注 + 云存储空间。
- **团队版**： seats + 共享 deck + 品牌主题。
- **一次性/买断**：可作促销（对标 NextPPT 买断心智），但订阅更健康。

### 7.3 定价（拟定，待定）
| 市场 | 免费 | Pro 月 | Pro 年（约 8 折） | 团队 |
|---|---|---|---|---|
| 中国 | ✓ | ¥29–39 | ¥290–390 | ¥99/人/月 |
| 欧美 | ✓ | $9–12 | $90–110 | $15–19/人/月 |

> 依据：国内同类（WPS AI/讯飞）订阅多在 ¥20–40/月；欧美 Gamma Plus ~$10/月、Beautiful.ai ~$12/月。我们凭「本地免费编辑器」可做价格下探+口碑获客。

### 7.4 支付与合规（待定，需一手调研）
- **中国**：微信支付 + 支付宝（个人/企业商户）；Web 服务需 **ICP 备案**；内容合规审核。
- **欧美**：Stripe + PayPal；**GDPR**（数据最小化、可删除、DPA）；选择 EU/US 区域合规托管（如 Frankfurt / us-east）；隐私政策 + ToS。
- **关键取舍**：编辑器本地优先天然契合 GDPR「数据不出本机」叙事；云端生成部分需明确告知哪些数据上云、可删除。

### 7.5 成本结构
- LLM token（生成）：按量，需毛利测算（订阅价需覆盖生成成本 +  margins）。
- 渲染算力（导出 PPTX/PDF）：可用用户本地浏览器（Playwright）卸载，云端仅兜底。
- 存储（云 deck/历史）：对象存储，低成本。

## 8. 市场进入顺序（GTM）

1. **中国先行（0–3 月）**：帆哥自身自媒体（帆哥的AI工具箱）作为冷启动渠道，免费编辑器引流 → Pro 订阅转化；微信/支付宝支付最快落地；无需海外合规。
2. **欧美跟进（3–6 月）**：英文 UI + Stripe/PayPal + GDPR 合规托管；通过 Product Hunt / Indie Hackers / X 引流，主打「local-first, privacy-first AI PPT」。
3. **双市场复用同一套 HTML deck 引擎**，边际成本低。

## 9. 风险与缓解
| 风险 | 缓解 |

| LLM 生成成本高、毛利薄 | 本地编辑器免费获客；生成按配额/阶梯计费；缓存复用模板 |

| 合规/支付门槛 | 中国先走、欧美合规后置；支付用成熟聚合 |
| 编辑器 P0 未完成 | 本期补全（拖拽缩放 + 代码视图） |
