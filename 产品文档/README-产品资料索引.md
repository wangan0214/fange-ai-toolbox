## 一句话产品形态

**Step 1 AI 生成**（主题/文档 → 可编辑 HTML deck）→ **Step 2 本地可视化编辑**（拖/缩/吸/代码视图，原地写回，零上传）→ **导出 PPTX/PDF/PNG**。
收费模型：**本地编辑免费 + 云端 AI 生成订阅**（Freemium 混合），中国先行、欧美后置。
